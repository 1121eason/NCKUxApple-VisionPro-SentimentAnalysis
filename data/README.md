# 公開資料字典

所有檔案是 2026-10-28 讀取 2023 年研究中間成果後製成的衍生資料。它們不是新蒐集的 2026 年消費者意見。

## historical_scores.csv

80 筆儲存的模型標籤，不含 K82 總平均。唯一鍵 `record_id`。列號指未排序的情緒分析主表。

| 欄位 | 定義 |
| --- | --- |
| record_id | 新增的 VP001–VP080 本地識別碼，不是網友帳號 |
| sheet_row | 原情緒分析表列號 2–81 |
| source_id | 對應 sources.csv；空白文字僅按區塊歸屬 |
| collection_rows | 原始蒐集表列號；合併片段以 `+` 連結 |
| source_assignment | 依文字比對、合併文字比對，或空白文字的區塊判定 |
| has_text | 快照中中文分析文字是否非空白，0 或 1 |
| text_length | 保留的中文分析文字字元數 |
| text_sha256 | 保留文字的 UTF-8 SHA-256；無文字留空 |
| sentiment | 歷史儲存的 positive／neutral／negative |
| score | 歷史儲存的數值；定義與閾值未恢復，不稱為置信度 |

## sources.csv

八個文章／討論串項目，記錄出版者、標題、原始連結、原表記載的文章日期與媒體類別。`editorial` 含新聞、評論、部落格，並不表示每一段都是新聞事實。`forum` 是討論片段。歷史網址未做目前可用性保證。

## historical_token_counts.csv

由歷史兩欄詞性工作表彙整出的 `term,pos,count`；共 1,001 個帶詞性項目的出現次數。保留原大小寫和詞性；程式後續的 casefold 與 POS／停用詞篩選另行進行。無逐文件邊界、無句序、無正負面連結，不能據此計算歷史 TF-IDF 或面向情緒。

## provenance.json

記錄版本日期、原始報告雜湊、選用的表範圍、空白列、公開方式與快照輸入雜湊。完整原始雲端 ID 與全文不公開。歷史中間資料可能在原研究後被修改；本次只能確認讀取時的狀態。

## 使用與權利

只用於檢查研究流程與方法。原文章及留言仍屬各自作者；本專案未對第三方內容授予再利用授權，也未附開放資料授權。原始文字、帳號、IP 與課程教材不在公開資料集內。`tests/fixtures/` 均為本次撰寫的合成範例。
