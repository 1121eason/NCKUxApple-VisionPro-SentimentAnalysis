# 分析方法：讓每一步都有可追溯的輸入

## 研究目的與分析單位

研究以 2023 年 Vision Pro 發表後的產品討論為背景，探索技術期待與購買門檻之間的差距。分析單位是「被研究者選入的文字片段」：新聞或部落格中的節錄，以及論壇回應。它不是獨立受訪者，也不是每篇文章一票。

## 1. 網路資料蒐集

原始蒐集表有 81 筆非空白片段，來自八個來源項目：三篇數位時代文章、科技宅啊高、班老大、兩串 PTT 討論及一篇天下雜誌文章，見 [來源目錄](../data/sources.csv)。有記載的來源日期介於 2023-06-06 至 2023-08-04；其中一個來源未填日期。這些是文章日期，不能當成爬取時間。

原報告描述使用 Excel／Google Sheets 蒐集與清理。PTT 工作表保留了含帳號或 IP 的原始行與去除附帶資訊後的文字欄；本次檢查的儲存格是靜態值，沒有足以證明當時爬蟲實作方式的公式或程式。課堂介紹 IMPORTXML／XPath，但教材教過某方法，不代表這份研究已實作該方法。

本次新增的 [scrape.py](../src/visionpro/scrape.py) 示範兩種明確擷取規則：

| 網頁型態 | 擷取範圍 | 排除項目 |
| --- | --- | --- |
| PTT HTML | 含 `push-content` class token 的 `span` | 評論者欄位、IP／時間欄位 |
| 新聞 HTML | `article` 之內的 `p` | 導覽、頁尾及非內文段落 |

程式處理 HTML entities、巢狀 inline 元素及空白，以「來源 URL + 清理後文字」建立去重鍵。同頁相同文字只保留一次，是內容去重，不能解讀成唯一使用者去重。遇到找不到目標節點會明確失敗，避免把整頁雜訊當成結果。新聞模板須另行檢查；此規則未宣稱適用所有網站。

## 2. 資料清理與來源追蹤

原始 81 個片段在清理後保留 80 個位置，其中 72 個位置仍有文字。逐筆比對顯示：十個原始片段未以獨立文字保留，其中兩段合併成一段，其餘八段未保留；原始清理理由沒有逐筆紀錄。本專案不替它們補寫理由。

本次新增的處理包括：

1. 以 `Comment` 原欄位比對蒐集表，恢復來源，再保留分析時的 `中文文本` 雜湊。
2. 對空白文字只保留所屬來源區塊，標為 `empty_text_source_context`，不補造評論。
3. 將分析表 K82 的平均值儲存格排除，避免誤當第 81 筆觀測。
4. 將內容與來源 metadata 分開，公開資料不散布完整原文、IP、帳號或雲端分享連結。
5. 新擷取程式採 Unicode NFKC 與空白正規化；保留「不／沒有」等否定詞及價格資訊。這項新清理規則未回寫歷史原文。

最後兩個天下雜誌節錄的來源資訊在清理表中位置不一致；第一段若單純向下填滿，會錯歸到前面的 PTT。本次依原始蒐集文字比對，將兩段都歸為 S08，見 [provenance](provenance.md)。

## 3. 翻譯與情緒分析

分析表有中文文本、英文翻譯、Sentiment、Score 欄位；原報告記載使用 Azure Machine Learning 的 Excel 情緒分析功能。這構成歷史工具使用與輸出證據。翻譯工具、Azure 模型版本、原始請求、分數定義與分類閾值均未保存，不能由數字反推為已知設定。

本次沿用儲存的 positive／neutral／negative 標籤與分數，只做重算，沒有依推測的閾值重新分類。分數不是經驗證的置信度；平均接近 0.5 也不證明多數文字中立。應同時檢視分布、原文語意及資料品質。

## 4. 中文文字探勘

歷史中間資料保留 `詞(詞性)` 的 CKIP 相容標註格式，以及拆成兩欄的詞與詞性；可確認有斷詞／詞性成果，但沒有重新執行斷詞服務。公開檔將其中 1,001 個帶詞性項目的出現次數彙整成 `term,pos,count`，不保留句序。

本次示範篩選 Na／Nb／Nc／Nv／FW、移除明列的停用詞、將英文大小寫合併，保留長度至少兩字的詞。這是新的可稽核篩選策略，不是對原 Power BI 視覺權重的精確復刻。因 Neu 與多數形容詞被排除，數字價格與「貴」會消失；分析價格議題必須另看原句與金額，不能只看此詞表。

本專案的 TF-IDF 實作使用 `TF=count/文件詞數`、`IDF=ln((1+N)/(1+df))+1`，不做向量長度正規化。它只在合成、已斷詞文件上展示。歷史公開詞頻沒有逐文件邊界，因此不能用它計算真實的歷史 TF-IDF，也不能宣稱原報告使用了 TF-IDF。

## 5. 視覺化與解讀

原報告有 Power BI 整體及正負面詞雲。詞雲可協助發現候選議題，但字體大小受到視覺設定與處理方法影響，不能直接當成統計顯著性、因果關係或重要性排名。本次另用相同分母規則製作情緒比較圖，讓空白紀錄的影響可以被檢查。
