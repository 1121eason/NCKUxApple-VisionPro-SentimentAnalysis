## 本次恢復資料的決策

- 以未排序的情緒主表為準；排序副本、正面表及負面表僅供交叉檢查，不串接成額外樣本。
- J2:K81 是 80 個儲存標籤，K82 是總平均，不是樣本。
- 8 個文字空白位置保留在公開分數檔，`has_text=0`；不虛構文字，不直接刪去歷史證據。
- 逐筆使用 Comment 對應原始蒐集表；雜湊對象則為情緒表的中文分析文本，兩欄可能有標點或文字編修差異。
- 一個論壇回應在蒐集表分成兩列，清理後合併；`collection_rows` 用 `+` 記錄。
- 一個天下雜誌片段在清理表中位於該來源標題之前，故依文字比對改歸 S08，避免錯歸 PTT。
- S07 原始網址以 `.htmll` 結尾。來源目錄保留錯字並加註，不默默修成已驗證網址。
- `has_text=1` 只表示快照保留文字，不等於內容有效、分類正確或抽樣具代表性。

## 公開範圍

本機私人封存包含三份原始 PDF、SHA-256 manifest、讀取快照及完整文本。課程講義不公開；原報告有學號、第三方圖像與指向原始資料的分享連結，故公開專案改提供新撰寫的個案 PDF。公開資料不含網友帳號、IP、完整文章、完整評論集合或雲端文件分享連結。

`data/historical_scores.csv` 保留列號、來源、文字是否存在、長度及 SHA-256；可在有權取得私人原文時核對。詞頻檔不保留句序。雜湊仍可能被已知原文比對，不代表匿名化的絕對保證。來源文章連結作為學術歸屬，文章文字與原始圖像仍屬各自權利人。

## 驗證與限制

本機測試涵蓋 HTML 範圍選擇、IP 排除、否定詞保留、去重、空結果失敗、網址輸入約束、歷史數字對帳及 TF-IDF 公式。這些檢查不等同於即時網站整合測試、Azure 模型驗證或市場研究驗證。

尚未執行：歷史來源即時爬取、Azure 重跑、完整人工標註與模型準確率評估、Power BI 原生報表重建、產業試驗或 Moodle 提交。GitHub Actions 的遠端執行狀態須以該次 workflow 的實際結果為準。

快照與原始報告雜湊見 [provenance.json](../data/provenance.json)。公開檔案完整性由根目錄 `SHA256SUMS` 記錄。
